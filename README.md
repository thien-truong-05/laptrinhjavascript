# ProSneaker - Website ban giay the thao

Website ban giay the thao xay dung bang Java Spring Boot va HTML/CSS/JavaScript.

## Chuc nang
- Hien thi danh sach giay va tim kiem theo ten/danh muc.
- Loc theo danh muc va sap xep gia.
- Them/xoa san pham trong gio hang, cap nhat so luong va tinh tong tien.
- Dang ky, dang nhap va dang xuat demo tren trinh duyet (localStorage).
- Bat buoc dang nhap truoc khi tien hanh dat hang.
- Giao dien responsive cho desktop va dien thoai.

## Cong nghe
- Java 17+
- Spring Boot 3.3
- Maven
- HTML5, CSS3, JavaScript

## Chay du an
1. Cai JDK 17+ va Maven.
2. Clone repository va mo thu muc du an.
3. Chay `mvn spring-boot:run`.
4. Mo `http://localhost:8080`.

Tai khoan demo khong duoc tao san; hay dang ky tai khoan trong giao dien. Ban dang nhap hien tai la demo phia trinh duyet, khong dung cho moi truong production. De trien khai that, can them backend authentication, database, validation va xu ly thanh toan an toan.
